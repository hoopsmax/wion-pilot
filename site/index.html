Wion-Pilot

AI-assisted test automation for web apps.

Wion-Pilot maps a web app's screens, records a scenario while you click through the app, and lets an AI draft more. Nothing enters the test suite until a person approves it. The tests are plain-language Gherkin running on Playwright, and every failure comes with a bug-report draft.

What it does

Map

wion map

Crawls the app and lists every screen, form field and rule, with a Playwright locator for each button, link and field. It never clicks or types anything apart from signing in.

Teach

wion teach

You click through the app in a browser, and each action becomes a step of a Gherkin scenario. No AI, no cost.

Draft and review

wion draft · wion review

An AI drafts scenarios from a topic or a code change, using only steps that already exist. A person approves each one.

Tested on every push

Everything is shown on Sprout, a small made-up plant-care app with the flows that are hardest to test: offline mode, and two people editing the same plant. CI runs the whole BDD suite on every push, and every failing test writes a bug-report draft. The report of the latest run on main is published here: open the live test report.
